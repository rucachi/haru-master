# 🧠 하루마스터 (HaruMaster)

> **중학교 1학년, 3학년 자녀를 위한 아빠표 에듀테크 관제 대시보드 & 에빙하우스(SRS) 스마트 복습 시스템**

---

## 🌟 프로젝트 개요

하루마스터(HaruMaster)는 아빠가 직접 설계하고 자녀의 학습 진도를 챙기는 패밀리 에듀테크 플랫폼입니다.  
학습 데이터는 **Cloud Firestore**를 단일 진실 공급원(Single Source of Truth)으로 삼아, **아빠용 웹 대시보드(GitHub Pages)**와 **아이들용 안드로이드 태블릿 앱**이 실시간으로 연동됩니다.

---

## 🛡️ 핵심 기능

### 1. 오류 제로(Zero-Error) 문제 출제 스튜디오
- **수학 LaTeX 수식 실시간 렌더링**: KaTeX 엔진을 탑재하여 분수(`\frac`), 거듭제곱, 제곱근(`\sqrt`), 그리스 문자 등이 태블릿 화면에서 깨짐 없이 나오는지 즉시 육안 검증
- **실시간 태블릿 에뮬레이터**: 아빠가 작성하는 문항이 10~11인치 태블릿 화면에 어떻게 배치되는지 100% 동일하게 실시간 렌더링
- **사전 비행 검사기(Pre-flight Validator)**: 보기 개수와 정답 번호 일치, LaTeX 괄호 짝 검사, 필수 해설 누락 여부를 0.1초 만에 전수 검사
- **텍스트 스마트 자동 변환기**: 시험지나 문제집에서 복사한 원문을 붙여넣으면 과목, 지문, 본문, 보기 1~5번, 정답, 해설로 자동 분리

### 2. 에빙하우스 망각곡선(SRS) 자동 복습 알고리즘
- **1일차 $\rightarrow$ 3일차 $\rightarrow$ 7일차 $\rightarrow$ 14일차**: 정답을 맞힐 때마다 복습 주기가 점진적으로 확장되어 장기기억으로 고착화
- **오답 시 즉시 1일차 리셋**: 틀린 문제는 즉시 1일 복습 큐로 리셋되며 `wrongCount`가 누적되어 요주의 취약 문항으로 집중 관리

### 3. 자녀별(중1, 중3) 실시간 모니터링
- 중학교 1학년 / 3학년 자녀 탭 원클릭 전환
- 오늘 배정된 일일 과제 현황, 정답률, 누적 학습량 시각화
- 2회 이상 틀린 요주의 취약 문항 집중 관리 및 원클릭 재풀이 큐 추가

## 🚀 깃허브 페이지(GitHub Pages) 배포 방법

하루마스터 웹 대시보드는 정적 웹(Pure HTML5 + Vanilla CSS + ES Modules JS)으로 빌드 없이 즉시 호스팅됩니다.

1. 이 저장소의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 선택합니다.
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정합니다.
4. **Branch**를 `main` 브랜치의 `/ (root)` 폴더로 지정하고 **Save**를 누릅니다.
5. 약 1분 후 `https://<깃허브아이디>.github.io/haru-master/` 주소로 전 세계 어디서나 무료로 접속할 수 있습니다!

---

## 💻 로컬 실행 방법

별도의 복잡한 설치 없이 브라우저에서 `index.html`을 바로 열거나 파이썬 내장 로컬 서버로 실행할 수 있습니다:

```bash
# 로컬 개발 서버 실행 (포트 8000)
python -m http.server 8000
```
브라우저에서 `http://localhost:8000`으로 접속하면 즉시 대시보드가 열립니다.
